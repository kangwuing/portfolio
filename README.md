# Research Portfolio

Personal research portfolio for Ngo Minh Khang, including research experience, education, academic publications, and selected personal projects.

## Personal project: TOEIC Reading Lab

The TOEIC Reading study app is available in [`toeic-study/`](toeic-study/) and is linked from the portfolio's **Personal Projects & Interests** section.

GitHub Pages publishes both surfaces together:

- `/portfolio/` — research portfolio;
- `/portfolio/toeic-study/` — TOEIC Reading Lab.

## Google Scholar publication sync

The Publications section is generated from the public Google Scholar profile
`6227iqYAAAAJ`. The Pages workflow refreshes the profile every six hours and on
each relevant deployment. If Scholar temporarily rejects an automated request,
the workflow deploys the last verified data in `data/publications.json` instead
of replacing the section with an empty result.

## Licenses and certifications

The portfolio includes four credentials verified against LinkedIn and the
issuers' public credential pages. The certificate PDF files supplied by the
portfolio owner are stored under `certificates/pdfs/` and linked from each
credential card.
